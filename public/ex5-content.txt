EXPERIMENT 5: K-NEAREST NEIGHBORS (KNN) CLASSIFICATION
========================================================

AIM
---
To classify Fashion-MNIST clothing images using the K-Nearest Neighbors (KNN) algorithm, compare different values of K, and evaluate performance using accuracy, prediction time, and a classification report.

DATASET
-------
Fashion-MNIST from OpenML:
- Total images: 70,000
- Each image: 28 x 28 grayscale pixels = 784 features
- Pixel values: 0 to 255 before scaling
- 10 clothing categories
- This experiment uses a stratified subset of 12,000 images:
  * Training: 10,000 images
  * Testing: 2,000 images

REQUIREMENTS
------------
Install if needed:
pip install numpy scikit-learn

FULL PROGRAM
------------

import numpy as np
import time

from sklearn.datasets import fetch_openml
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score, classification_report

# 1. Load the Fashion-MNIST dataset
fashion_mnist = fetch_openml(
    "Fashion-MNIST",
    version=1,
    as_frame=False
)

X = fashion_mnist.data
y = fashion_mnist.target.astype(int)

print(
    f"Total dataset size: {X.shape[0]} images, "
    f"each with {X.shape[1]} pixels."
)

# 2. Select a stratified subset of 12,000 images
X_subset, _, y_subset, _ = train_test_split(
    X,
    y,
    train_size=12000,
    stratify=y,
    random_state=42
)

# 3. Split the subset into training and testing sets
X_train, X_test, y_train, y_test = train_test_split(
    X_subset,
    y_subset,
    test_size=2000,
    stratify=y_subset,
    random_state=42
)

print(f"Training images: {X_train.shape[0]}")
print(f"Testing images: {X_test.shape[0]}")

# 4. Scale pixel values from 0-255 to 0-1
print(f"Before scaling -> Min: {X_train.min()}, Max: {X_train.max()}")

X_train = X_train / 255.0
X_test = X_test / 255.0

print(f"After scaling -> Min: {X_train.min()}, Max: {X_train.max()}")

# 5. Try different K values and measure accuracy and prediction time
k_values = [1, 3, 5, 7, 9, 15]
results = {}

print(f"{'K value':<8} | {'Accuracy':<10} | {'Prediction Time (seconds)':<25}")
print("-" * 55)

for k in k_values:
    knn = KNeighborsClassifier(
        n_neighbors=k,
        metric="euclidean",
        n_jobs=-1
    )

    # KNN stores training examples; fit prepares the model
    knn.fit(X_train, y_train)

    start_time = time.time()
    y_pred = knn.predict(X_test)
    elapsed_time = time.time() - start_time

    acc = accuracy_score(y_test, y_pred)

    results[k] = {
        "accuracy": acc,
        "time": elapsed_time,
        "predictions": y_pred
    }

    print(f"{k:<8} | {acc * 100:<9.2f}% | {elapsed_time:25.2f}")

# 6. Find the K value with the highest accuracy
best_k = max(results, key=lambda k: results[k]["accuracy"])

print(
    f"\\nBest K is: {best_k} with "
    f"{results[best_k]['accuracy'] * 100:.2f}% accuracy\\n"
)

# 7. Display the classification report for the best K
class_names = [
    "T-shirt/top",
    "Trouser",
    "Pullover",
    "Dress",
    "Coat",
    "Sandal",
    "Shirt",
    "Sneaker",
    "Bag",
    "Ankle boot"
]

print("Per-class Classification Report:")
print(
    classification_report(
        y_test,
        results[best_k]["predictions"],
        labels=list(range(10)),
        target_names=class_names,
        zero_division=0
    )
)

IMPORTANT NOTES / EXPLANATION
-----------------------------
1. KNN stands for K-Nearest Neighbors.
2. KNN is a supervised machine-learning algorithm used for classification and regression.
3. In classification, KNN finds the K closest training examples to a new example and predicts the most common class among those neighbors.
4. X contains image pixel features; y contains clothing-category labels from 0 to 9.
5. Every image is 28 x 28 pixels, so it contains 784 pixel features.
6. fetch_openml() downloads/loads Fashion-MNIST. An internet connection may be needed on the first run.
7. stratify=y keeps class proportions approximately balanced when splitting the data.
8. random_state=42 makes the data split reproducible.
9. test_size=2000 means 2,000 examples go into the test set; the remaining 10,000 are training examples.
10. Dividing pixel values by 255 converts the range 0-255 into 0-1.
11. Scaling is useful because KNN relies on distances. In this experiment all pixel features share the same original scale.
12. n_neighbors=k specifies how many neighbors vote on the predicted class.
13. metric="euclidean" uses straight-line Euclidean distance.
14. n_jobs=-1 asks scikit-learn to use available CPU cores for supported computation.
15. fit() stores/prepares the training examples; unlike many models, basic KNN does not learn a compact set of parameters.
16. predict() finds neighbors for each test image and returns predicted labels.
17. accuracy_score() calculates the fraction of correct predictions.
18. classification_report() shows precision, recall, F1-score, and support for each category.
19. Support is the number of true test examples belonging to a class.
20. A very small K can be sensitive to noise. A very large K can over-smooth decisions and may reduce accuracy.
21. The best K is selected from the tested values based on test-set accuracy in this lab. In a rigorous machine-learning workflow, select K using validation data/cross-validation and keep the test set for final evaluation.
22. The class names map numeric labels 0-9 to clothing categories.
23. The original notebook has a typo "Ankled boot"; the standard class name is "Ankle boot".
24. KNN prediction can be computationally expensive because it compares each query with many training examples.

VIVA QUESTIONS AND ANSWERS
--------------------------

1. What is KNN?
   K-Nearest Neighbors is a supervised algorithm that predicts a sample's class using the labels of its nearest training samples.

2. What does K stand for?
   The number of nearest neighbors considered when making a prediction.

3. Is KNN supervised or unsupervised?
   Supervised, because it learns from labelled training examples.

4. Is KNN a classification or regression algorithm?
   It can do both. Classification uses a class vote; regression typically averages neighbor target values.

5. How does KNN classify a new image?
   It calculates distances to training images, selects the K closest images, and predicts the most frequent class among them.

6. What is Fashion-MNIST?
   A dataset of grayscale clothing images with 10 categories, commonly used for image-classification experiments.

7. How many pixels are in each image?
   784 pixels, because 28 x 28 = 784.

8. Why are pixel values divided by 255?
   To normalize values from 0-255 to the range 0-1.

9. What is Euclidean distance?
   The straight-line distance between two feature vectors: sqrt(sum((x_i - y_i)^2)).

10. What happens when K=1?
    The predicted class is the class of the single nearest training example.

11. What happens if K is too small?
    Predictions can be sensitive to noise and individual examples, potentially overfitting.

12. What happens if K is too large?
    The vote can include distant or less relevant examples, potentially underfitting.

13. Why try multiple K values?
    To compare performance and identify a useful neighbor count.

14. Why use train_test_split()?
    To divide data into separate training and testing sets.

15. What does stratify=y do?
    It maintains approximately the same class distribution in the resulting splits.

16. What does random_state=42 do?
    It makes the random split reproducible.

17. What does fit() do in KNN?
    It stores the training feature vectors and labels for later neighbor searches.

18. What does predict() do?
    It predicts a class label for each input sample using its nearest neighbors.

19. What is accuracy?
    The number of correct predictions divided by the total number of predictions.

20. What is precision?
    The proportion of predictions for a class that are correct.

21. What is recall?
    The proportion of actual examples of a class that the model correctly identifies.

22. What is the F1-score?
    The harmonic mean of precision and recall.

23. What is support in a classification report?
    The number of actual test examples belonging to each class.

24. Why can KNN be slow at prediction time?
    It may need to calculate distances between each query and many stored training examples.

25. What is the main disadvantage of KNN?
    It can be computationally expensive and memory-intensive for large datasets.

26. Which K performed best in the reference run?
    K=7, with approximately 81.10% accuracy. Your result may differ slightly.

27. What is the role of n_jobs=-1?
    It requests use of all available CPU cores for computations where scikit-learn supports parallel processing.

28. Why is scaling important for distance-based algorithms?
    Features with larger numeric ranges can dominate distance calculations; scaling puts features on comparable ranges.

CONCLUSION
----------
The Fashion-MNIST dataset was classified using K-Nearest Neighbors with several K values. Accuracy and prediction time were compared, and a classification report was generated for the best-performing tested K. In the reference run, K=7 achieved approximately 81.10% accuracy.
